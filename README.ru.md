**Неофициальный порт Compositor для macOS 13 Ventura с целевыми архитектурами Intel и Apple Silicon.**

Compositor создан **Robbie Tilton и участниками оригинального проекта**. Исходные авторские права: **© 2026 Wonder Assembly LLC**. Основной проект находится здесь: **[robbietilton/Compositor](https://github.com/robbietilton/Compositor)**. Также доступен [официальный сайт](https://robbietilton.com/compositor).

Этот репозиторий содержит адаптацию для Ventura и материалы для её сборки. Мы не присваиваем авторство программы. Это не официальный релиз и не проект, одобренный авторами оригинала. Исходная [MIT-лицензия](LICENSE) и уведомление об авторских правах сохранены.

## Compositor 1.5.5 — сборка 51.1 для Ventura

Основа — оригинальная **v1.5.5**, коммит [`b31ea029`](https://github.com/robbietilton/Compositor/commit/b31ea029762ecb782699df971e1412168602a44d). Сохранены RGB Split, новые корректирующие слои, Channel Pack, Photoshop artboards и изменения версии 1.5.4. См. [разбор переноса](docs/UPGRADING-1.5.5.md).

**24 октября 2026 года владелец порта подтвердил запуск и начальную работу сборки 51.1 на Intel с macOS 13.7.8 (22H730).** Это не полная проверка всех функций. **Нативная работа на Apple Silicon с macOS Ventura пока не подтверждена.**

**Совместимость проектов:** 1.5.5 сохраняет `.comp` формата **16**, который 1.5.3 не открывает даже без новых эффектов. Сохраните исходные проекты отдельно перед сохранением в 1.5.5.

## Скачать и установить

Откройте [релиз Compositor 1.5.5 — сборка 51.1](https://github.com/cortez777rus/Compositor-Ventura/releases/tag/v1.5.5-ventura.1).

1. В разделе **Assets** выберите **`Compositor-1.5.5-Ventura-universal.zip`**.
2. Закройте старую копию приложения, распакуйте архив и перенесите `Compositor.app` в **«Программы»** с заменой, если нужно.
3. Откройте установленную копию. Сборка подписана локальной ad-hoc подписью, **без нотариального заверения Apple**. Если macOS блокирует открытие, воспользуйтесь разрешением для этого приложения в **«Системные настройки → Конфиденциальность и безопасность»**, если система его предлагает.

Xcode и учётная запись GitHub для скачивания и запуска не нужны. Полный изменённый проект Xcode находится в отдельном файле **`Compositor-1.5.5-Ventura-source.zip`**. Автоматические ссылки GitHub **Source code** содержат только этот набор патчей и сценариев сборки.

При дальнейшем распространении сохраняйте [уведомления о лицензиях](THIRD_PARTY_NOTICES.txt). Предыдущий [релиз 1.5.3 / 49.2](https://github.com/cortez777rus/Compositor-Ventura/releases/tag/v1.5.3-ventura.2) остаётся доступен.

## Отличия и ограничения

- Автоматическое выделение объектов и удаление фона на Ventura используют запасной алгоритм Core ML/Vision. Результат может отличаться от оригинала для новой macOS.
- **RAW Highlight Recovery на Ventura недоступен.** Поддержка камер зависит от RAW-декодера системы.
- Часть элементов интерфейса заменена доступными в Ventura аналогами.
- Официальное автообновление отключено, чтобы не установить несовместимую версию. Обновления порта нужно устанавливать вручную.
- Оригинальная 1.5.5 сохраняет `.comp` формата 16, который версия 1.5.3 не открывает. Порт сохраняет это поведение; оставьте исходные проекты отдельно и проверяйте обновление на копиях.

Предыдущая внутренняя сборка 49 падала при запуске; используйте текущий релиз или историческую **49.2**. См. [список изменений](CHANGELOG.md).

## Исходники и самостоятельная сборка

Репозиторий хранит [читаемый патч](patches/ventura-1.5.5.patch) к оригинальному проекту и сценарии сборки. Полные исходники можно получить так:

```bash
git clone https://github.com/cortez777rus/Compositor-Ventura.git
cd Compositor-Ventura
bash scripts/prepare-source.sh
```

Они появятся в `build/Compositor`. Для компиляции нужен **Xcode 26.6 на более новой поддерживаемой macOS**. Альтернатива — сделать fork этого репозитория и запустить **Actions → Ventura Build → Run workflow**. Обновлять Mac с Ventura, на котором будет работать приложение, не требуется. [Инструкция сборки](docs/BUILDING.md).
